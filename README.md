## 核心洞察

1. **内蒙古占全国83.6%挂牌量** — 能源大省的资产处置需求远超其他地区
2. **央企"两非两资"清理是最大供给来源** — 中石油、华能、中国重汽、中国石化等在多地挂牌
3. **三四线城市大宗资产流动性枯竭** — 通辽4亿办公大楼三度降价仍终止
4. **银行系"清不良"全面加速** — 中信银行、光大银行、中国银行等批量处置自有房产
5. **二手设备市场存在显著套利空间** — 浪潮服务器溢价121%，国金电动车溢价32%
6. **城投平台债务压力驱动资产处置** — 烟台业达系、淄博城投等密集卖资产换流动性
7. **"新旧产能置换"是工业资产处置主因** — 智能工厂投产淘汰旧产线
8. **农村集体资产市场化加速** — 安徽农村产权交易网315条土地经营权流转
