## 核心洞察

1. **国企"两非两资"清理是最大供给来源** — 超过70%的资产来自国企剥离非主业资产
2. **三四线城市大宗资产流动性枯竭** — 通辽4亿办公大楼三度降价仍终止，是最好的证明
3. **银行系"清不良"全面加速** — 中信银行、光大银行等批量处置自有房产
4. **二手设备市场存在显著套利空间** — 浪潮服务器溢价121%，国金电动车溢价32%
5. **央企"瘦身健体"战略持续深化** — 鲁能/中国绿发、中煤、烟草等均在清理非核心资产
6. **城投平台债务压力驱动资产处置** — 烟台业达系、淄博城投等密集卖资产换流动性
7. **"新旧产能置换"是工业资产处置主因** — 岱岳制盐智能工厂投产、海纳川减资等
8. **农村集体资产市场化加速** — 莱芜区土地经营权、创业大厦使用权等集体资产入市流转

## 数据来源与更新

- **数据来源：** 山东产权交易中心（sdcqjy.com）及全国产权交易市场公开数据
- **更新频率：** 每日自动更新（GitHub Actions）
- **调查方法：** 企业工商信息查询、司法诉讼核查、行业动态追踪、财务报告分析、网络公开信息交叉验证

## 技术架构

- **前端展示：** 纯 HTML/CSS/JavaScript，无框架依赖，GitHub Pages 托管
- **数据获取：** Node.js 脚本，定时调用数据接口并解析
- **自动化：** GitHub Actions 每日定时运行，自动更新数据并推送
- **深度调查：** 结合 Web Search 进行逐项背景调查和动因分析
